# 面板语言切换使用指南

## 🌐 功能概述

dsh-context-hub 面板现在支持图形化语言切换，无需使用命令行。

## 📱 使用步骤

### 1. 打开面板

点击 DSH 界面右下角的 **上下文中枢** 按钮，或按 `Esc` 键打开面板。

### 2. 切换到语言标签页

在面板顶部标签栏中，点击 **语言** 标签。

### 3. 选择语言

在语言列表中点击任意语言按钮即可切换：

- **自动检测** - 跟随系统语言
- **中文** - 简体中文
- **English** - 英文
- **日本語** - 日文
- **한국어** - 韩文
- **Deutsch** - 德文
- **Français** - 法文
- **Español** - 西班牙文

### 4. 确认切换

- 当前启用的语言会高亮显示
- 面板文本立即更新为新语言
- 设置自动保存到记忆库

## 🎯 特性

### 覆盖范围

面板内**所有可见文案**都随语言切换，不只是标签页：

| 区域 | 内容 |
|------|------|
| 标题栏 | 面板标题、副标题、刷新/关闭按钮、加载态 |
| 胶囊按钮 | 上下文百分比、记忆条数、待审核提示、悬浮说明 |
| 概览页 | 上下文构成、压缩账本、成本曲线、活动 Top、请求采样 |
| 记忆页 | 记忆库统计、按范围/按类型图例、最近记忆、待审核列表、表头与行内按钮 |
| 观测页 | 上下文明细、压力/窗口、注入、输出预留、已折叠、召回车道、事件表 |
| 配置页 | 能力标签、召回预算、记忆 TTL、抽取与冲突、语义召回开关、压缩与接管、模式 |
| 语言页 | 语言列表与当前设置 |
| 其他 | 空态文案、错误提示、表格表头、工具提示（title/aria-label） |

> 语言名称（简体中文 / 日本語 / 한국어）按各自语言显示，属于有意保留。

### 即时生效

点击语言按钮后，面板的标题、标签页、按钮、区块标题立即切换到所选语言：
- ✅ 无需刷新页面（客户端状态驱动，localStorage 记忆偏好）
- ✅ 无需重启 DSH（语言偏好先本地生效，再尽力同步到记忆库）
- ✅ `自动检测` 时按浏览器 `navigator.language` 选择（zh / en / ja，其余回退中文）
- ✅ 子组件（表格、图例、按钮）通过模块级 `tr()` 取词，与面板同步

### 持久化

- ✅ 语言偏好写入浏览器 `localStorage`（键 `context-hub.locale`）
- ✅ 同时尝试写入记忆库 `config:locale`（服务端重启后由 API 读取）
- ✅ 命令行 `/context-hub locale <code>` 与面板共用同一份设置

> 说明：面板文案由前端字典渲染（zh / en / ja）。若服务端尚未重启，`locale` 写入会静默失败但不影响面板切换；重启 DSH 后即可持久化。

### 回归测试

```bash
npm run test:panel-i18n
# 用桩化 React 渲染 5 个标签页 × 中英文，
# 断言英文模式不残留中文 → PANEL I18N OK
```

### 自动检测

选择 **自动检测** 模式后：
- 根据系统环境变量自动选择语言
- 支持 LANG, LC_ALL 等标准变量
- 默认回退到中文

## 🖥️ 命令行方式

也可以使用命令行切换语言：

```bash
# 查看当前语言
/context-hub locale

# 切换到中文
/context-hub locale zh

# 切换到英文
/context-hub locale en

# 自动跟随系统语言
/context-hub locale auto
```

## 📊 支持的语言

面板与命令行共用同一份词表：每种语言 **257 个词条**全覆盖，无中文回退。

| 语言代码 | 语言名称 | 词条 | 校验 |
|---------|---------|------|------|
| auto | 自动检测（浏览器语言） | — | ✅ |
| zh | 简体中文 | 257/257 | ✅ |
| en | English | 257/257 | ✅ |
| ja | 日本語 | 257/257 | ✅ |
| ko | 한국어 | 257/257 | ✅ |
| de | Deutsch | 257/257 | ✅ |
| fr | Français | 257/257 | ✅ |
| es | Español | 257/257 | ✅ |

词表位置：

```
scripts/locale-data/
├── _keys.json   # 权威键清单（257 键，构建校验用）
├── ja.json      # 日语词表（扁平键 → 文本，支持 {0} 占位符）
├── ko.json
├── de.json
├── fr.json
└── es.json
```

中文与英文词表内联在 `client/client.js` 的 `DICT`/`EXTRA` 中（作为兜底），
其余语言由 `scripts/build-client-locales.mjs` 在构建期内联为 `EXTRA_MORE`。

### 词表工作流

```bash
npm run build:locales    # 把 locale-data/*.json 内联进 client.js
npm run check:locales    # 校验 client.js 与词表是否同步、键是否齐全
npm run test:panel-i18n  # 7 语言 × 5 标签页真实渲染，断言无漏翻
```

新增语言只需：在 `scripts/locale-data/` 添加 `<code>.json`（照 `_keys.json` 填满），
在 `build-client-locales.mjs` 的 `LANGS` 里加一项，再在面板语言列表里加一行。

## 🔧 配置位置

语言设置保存在：
- **记忆库**：`~/.dsh/context-hub/memory.db` (kv 表)
- **配置文件**：`~/.dsh/context-hub/config.json` (可选)

## 🐛 故障排查

### 语言切换后没有变化

1. 刷新面板（点击刷新按钮或按 F5）
2. 检查是否选择了正确的语言
3. 查看浏览器控制台是否有错误

### 重启后语言重置

1. 检查记忆库是否正常
2. 确认配置已保存：`/context-hub locale`
3. 手动重新设置语言

### 某些文本仍是旧语言

1. 部分系统文本可能缓存
2. 完全关闭并重新打开 DSH
3. 清除浏览器缓存
